02 / Open Source & Prototypes

AgentOS for Android — Creator HanZijie/agentos-android ↗

"Agent 不必是入口，也可以是系统服务。"

探索不依赖中心化聊天入口的移动端公共 Agent 运行时原型：多个 App 共用同一套底层 Agent Runtime，任务在原 App 内发起并原位返回结果，调用方无需内置模型与推理循环。

  • Architecture：以 ACP 连接任务入口、MCP 连接能力提供方、Plugin 组织工具与 Skill；Kotlin 宿主负责身份、会话与调度，QuickJS 承载轻量化 Agent Core，解耦 Android 接口、底层模型与 Agent Loop。
  • Isolation & Permission：基于 Binder 识别调用方身份并隔离会话，支持首次授权、随时撤销及写操作显式确认；以 Magisk / KernelSU 模块形态验证备忘录、日历、闹钟等跨应用双向调用（非 root 身份运行 Agent 与插件进程）。
